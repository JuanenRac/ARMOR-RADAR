A.R.M.O.R. - node setup code

Enter the fleet secret (the same one in secrets/generic.conf, never in the repository) and a node's MAC address to get the ten-character code its own set-up screen expects - the same code tools/adopt_node.py would print, computed the same way (HMAC-SHA256 of the MAC with the fleet secret). This page makes no network request: the secret never leaves this browser tab, and nothing here is saved when it is closed.
